# assistant-gg

Bot de Starvios para Mari y Sebas, o solo una de las dos cuentas. Cada bot
configurado usa su propia cuenta (login con email/contraseña o sesión de Supabase
como respaldo). Si solo configuras una cuenta, el bot funciona con esa cuenta.
Para preparar la prueba de micrófono con OBS, sigue
[CONFIGURACION.md](CONFIGURACION.md). El puente usa un Cloudflare Quick Tunnel
temporal y no requiere R2.
